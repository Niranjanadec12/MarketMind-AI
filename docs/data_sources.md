# MarketMind AI — Data Sources and Attribution

## 1. Brazilian E-Commerce Public Dataset by Olist

MarketMind AI uses data from the **Brazilian E-Commerce Public Dataset by Olist**, published on Kaggle.

- **Provider:** Olist
- **Source:** https://www.kaggle.com/olistbr/brazilian-ecommerce
- **Dataset license listed by the source:** Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)

The dataset contains anonymized Brazilian e-commerce order information and related customer, product, seller, payment, review, and geographic records.

The project processes source data into cleaned and analytical CSV files for dashboard reporting and machine-learning experiments.

The original dataset's license applies independently of the software license in this repository. Review the original license terms before redistributing the dataset or using it in a commercial context.
